# Cyber Security Internship – Task 11
## Phishing Attack Simulation & Detection

### 📌 Objective
The objective of this task is to understand phishing attacks, simulate a phishing campaign using GoPhish, analyze user behavior, and learn methods to detect and prevent phishing attacks.

---

### 🛠 Tools Used
- GoPhish (Open-source phishing simulation framework)
- Web Browser
- GitHub

---

### ⚙️ Task Description
A phishing attack simulation was performed using GoPhish. A fake email template and landing page were created to demonstrate how attackers trick users into revealing sensitive information. The campaign was launched on test users only for educational purposes.

---

### 🧪 Steps Performed
1. Installed and configured GoPhish
2. Created a fake phishing email template
3. Created a fake login landing page
4. Added test users and groups
5. Configured a dummy SMTP sending profile
6. Launched phishing campaign
7. Observed campaign results
8. Identified phishing indicators and prevention techniques

---

### 📊 Outcome
- Understanding of phishing attack methodology
- Awareness of social engineering techniques
- Knowledge of phishing detection and prevention

---

### ⚠️ Disclaimer
This project is strictly for educational purposes. No real users or real email accounts were targeted.
